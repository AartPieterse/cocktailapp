# Barkast frontend

The **Barkast** web frontend: an **installable, offline-capable Angular PWA** whose hero feature is
*"wat kan ik maken"* (your cabinet → cocktails you can make right now). UI copy and most route paths
are Dutch; the data language is English with a Dutch overlay (see [`docs/data-model.md`](../docs/data-model.md)).

## Tech stack

- **Angular 21.2.x**, fully **standalone** (`bootstrapApplication`), **signals-driven**, **zoneless**
  (`zone.js` is not a dependency).
- **Angular Material + CDK 21.2**; editorial theme (Fraunces + Inter) with light/dark mode.
- **TypeScript 5.9**, **RxJS 7.8**.
- **`@cocktailapp/shared`** for domain types and `computeMakeable` / `expandCabinet`.
- Tests: **Vitest** (`@angular/build:unit-test`, jsdom). No e2e framework configured.

## Routes

Lazy-loaded standalone routes inside a `Layout` shell. Defaults redirect to **`/ontdek`**:

| Path | Screen |
| --- | --- |
| `/ontdek` | **Ontdek** — makeable / bijna discovery (`Bar` component) |
| `/bar` | **Mijn bar** — toggle what you own (`Cabinet`) |
| `/bar/wizard` | First-run / rebuild wizard (finish → `/ontdek`) |
| `/kast` | Redirect → `/bar` (back-compat) |
| `/cocktails` | Search, tags, favorites, detail |
| `/ingredienten` | Ingredient list |
| `/account` | Account UI (only useful when `authEnabled`) |

Catalog authoring routes (`add`, `:id/edit`) are registered only when `environment.admin` is true
(dev), not in production.

## Local-first & data source

Persistence is **`localStorage`** (writes wrapped in try/catch):

| Key | Purpose |
| --- | --- |
| `barkast.cabinet` | Owned ingredient ids |
| `barkast.wizardDone` | Wizard completed |
| `barkast.favorites` | Favorite cocktail ids |
| `barkast.theme` | light / dark |
| `barkast.locale` | `nl` / `en` |
| `barkast.units` | Preferred measure units |
| `barkast.substitutes` | "Vervangers meetellen" (default on) |
| `barkast.install.dismissed` | PWA install snooze |
| `barkast.auth` / `barkast.sync` / `barkast.analyticsOptOut` | Used only when auth/analytics are enabled |

- **Dev** (`dataSource: 'api'`): NestJS at `http://localhost:3000/api/` for authoring.
- **Production** (`dataSource: 'static'`): bundled `catalog.json` + `catalog.nl.json`; makeable is
  computed client-side. Static services reject writes.
- Auth, sync, and analytics **code exists** but is gated by `authEnabled` / `analyticsUrl`
  (`environment.prod.ts`: `authEnabled: false`, empty `analyticsUrl`). The shipped static site sends
  nothing about you to a server.

## PWA

- **Manifest** (`public/manifest.webmanifest`): name *"Barkast — wat kan jij maken?"*, `standalone`,
  theme `#17120c`, 192/512/maskable icons, app shortcuts.
- **Service worker** (`public/sw.js`): network-first navigations (offline shell), cache-first for
  content-hashed assets, stale-while-revalidate for other same-origin assets/fonts, passthrough for
  `/api/`. Hand-written (not ngsw). `CACHE_VERSION` is `barkast-${BUILD_ID}` stamped by
  `scripts/stamp-sw.mjs` at build time. Registered in `main.ts` **only in production**.
- **Install:** `beforeinstallprompt` on Chromium; guided sheet on iOS Safari. Mobile-only; dismiss
  snoozes 14 days.
- **Mobile:** `viewport-fit=cover`, safe-area padding, 16px inputs under 560px, ≥48px tap targets on
  the install sheet.

## Cross-cutting

- **Theme:** `ThemeService` persists light/dark, sets `<html data-theme>`, syncs `theme-color`
  (`#f4ebd8` / `#17120c`).
- **HTTP errors:** `apiErrorInterceptor` → Dutch `MatSnackBar` (status 0 → *"Geen verbinding met de
  server"*).
- **Router:** `withComponentInputBinding()`, scroll restoration to top.

## Development

From the **repo root**:

```bash
npm run build:shared      # compile @cocktailapp/shared
npm run start:frontend    # ng serve on http://localhost:4200
npm run start:backend     # optional, for authoring
npm run dev               # shared + backend + frontend
```

Within `frontend/`:

```bash
npm start                 # ng serve (development)
npm run watch             # ng build --watch --configuration development
npm run build             # production build
npm test                  # Vitest
```

Environments (`angular.json` `fileReplacements`): `environment.ts` → `environment.prod.ts`.
`apiUrl` must end with a trailing slash.

## Production build & deploy

Static SPA on **Netlify** (`dist/frontend/browser`, `NODE_VERSION=24`). SPA fallback:
`public/_redirects` (`/* /index.html 200`). Catalog bundle is generated by root
`npm run build:catalog`. See [`README.md`](../README.md) and `netlify.toml`.
